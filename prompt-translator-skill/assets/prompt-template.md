# SPACES Prompt Template

Use this template as a starting point for any prompt. Fill in the sections that apply — not every section is needed for every prompt.

---

## Template (Fill-in-the-Blanks)

```
你是[角色身份]，[专业背景]，擅长[具体能力]。你的产出面向[受众]。

请完成以下任务：

[具体任务描述，包括目标、输入数据、期望结果]

按以下结构输出：
1. [第一部分] — [该部分的简短说明]
2. [第二部分] — [该部分的简短说明]
3. [第三部分] — [该部分的简短说明]

约束条件：
- [格式/长度/风格要求]
- [禁止事项]
- [不确定时的处理方式]

示例输入：
[提供一个具体示例的输入]

示例输出：
[提供对应的期望输出]
```

---

## Minimal Template (When in a Hurry)

```
你是[角色]。请[任务]。面向[受众]。

输出：[格式要求]。

注意：[1-2个最重要的约束]。
```

---

## Template by Use Case

### Analysis
```
你是[领域]分析师。分析[数据/情况]，判断[具体问题]。

结构：核心发现 → 数据支撑 → 建议。

约束：[语言/长度/置信度标注要求]
```

### Writing
```
你是[作者身份]。为[受众]写一篇关于[主题]的[文章类型]。

字数：[范围]
风格：[调性描述]
结构：[段落安排]

避免：[禁忌]
```

### Coding
```
用[语言]实现[功能]。输入：[参数]。输出：[返回值]。

要求：[性能/可读性/测试]
不要：[反模式]
```

### Decision Support
```
你是[顾问身份]。帮我做[决策]。

背景：[相关信息]
选项：[选项A / 选项B / 选项C]

对每个选项评估：[评估维度，如成本、风险、时间]
最终推荐：[哪个选项 + 为什么]

如果不确定某个评估，请标注置信度。
```

### Learning/Explanation
```
你是[领域]的教育者。向[学习者背景]的人解释[概念]。

要求：
- 用[比喻/类比]帮助理解
- 从简单到深入，分层次讲解
- 给出3个实际应用场景
- 常见误解澄清

如果某个类比不完美，请指出其局限。
```
